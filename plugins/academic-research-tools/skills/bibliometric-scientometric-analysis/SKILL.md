# Bibliometric and Scientometric Analysis

## The Problem This Solves

A literature review is not just about what papers say; it is also about how the field is structured. Who are the central authors? Which institutions collaborate? How have keywords evolved over time? Which papers form the intellectual backbone of the field? What lexical classes structure the discourse?

This skill answers those questions by processing the OpenAlex JSON corpus generated by `verified-paper-search` through a combination of **pyBibX** (Pereira, Basilio & Santos, 2025) for science mapping, and a dedicated text analysis pipeline using **spaCy**, **Gensim**, and **scikit-learn** for topic modelling and hierarchical lexical classification. It generates interactive HTML visualizations and static plots, and provides interpretive, data-grounded commentary for each output.

## Workflow

### Pre-Flight: Verify Input Corpus

Before starting, locate the JSON file exported by `verified-paper-search` (e.g., `/home/ubuntu/articles/openalex_corpus.json`).

**If the file does not exist:** Ask the user to provide it or to run `verified-paper-search` first.
**If the file exists:** Read the file to determine the corpus size (number of papers) and confirm that abstracts are present, since Groups 5 and 9 require abstract text.

### Step 1 — Select Analyses (User Driven)

Do not run all analyses blindly. Present the following menu to the user, grouped by purpose. Note corpus size warnings where applicable.

| Group | Analyses Available | Purpose | Min. Corpus |
|---|---|---|---|
| **1. Descriptive/EDA** | Publications per year, citations per year, document types, languages | Basic overview of the field's size and growth | Any |
| **2. Author Analysis** | Most productive authors, H-index table, author productivity plot | Identifying key researchers and their impact | Any |
| **3. Source/Venue Analysis** | Most productive journals, Bradford's Law (core sources) | Identifying where the conversation is happening | Any |
| **4. Geographic Analysis** | Countries per documents, world map collaboration | Mapping the global distribution of research | Any |
| **5. Keyword Analysis** | Keyword co-occurrence network, term growth plot, WordCloud | Tracing how concepts and terminology evolve | 10+ |
| **6. Citation Analysis** | Top cited references, Reference Publication Year Spectroscopy (RPYS) | Identifying foundational works and historical shifts | 15+ |
| **7. Network Analysis** | Co-authorship network, institutional collaboration | Mapping the social structure of the field | 20+ |
| **8. Advanced/Strategic** | Burst detection, Disruption index, Sleeping Beauties | Finding emerging trends and paradigm shifts | 30+ |
| **9. Text Analysis** | Two submethods (see below) — requires abstracts | Lexical and topical structure of the discourse | 15+ |

**For Group 9, present the two submethods separately and ask the user to select one or both:**

| Submethod | Method | Output | Min. Corpus |
|---|---|---|---|
| **9a. LDA Topic Modelling** | spaCy preprocessing + Gensim LDA + pyLDAvis | Interactive HTML bubble chart of topic clusters with top terms per topic | 15+ |
| **9b. Hierarchical Descending Classification (CHD)** | spaCy + TF-IDF + scipy Ward linkage | Dendrogram with labelled lexical classes and top terms per class (IRAMUTEQ-style) | 15+ |

**🛑 STOP: Ask the user which groups (and, for Group 9, which submethods) they want to run. Wait for their selection before proceeding.**

For Group 9, extract the abstract text from the JSON into a list of strings for the text analysis pipeline.

### Step 3 — Execution & Output Generation

Execute the selected analyses using Python. Save all outputs into a dedicated directory (e.g., `/home/ubuntu/articles/bibliometrics/`).

**For Groups 1 to 8:** Use pyBibX to generate interactive `.html` plots. If pyBibX fails to install or crashes, fall back to `pandas` and `plotly` for static charts.

**For Group 9a (LDA Topic Modelling):** Run the following pipeline:

1. **Preprocessing with spaCy:** Tokenize, lemmatize, remove stopwords, and filter to keep only nouns and verbs (POS tags NOUN and VERB). Remove tokens shorter than 3 characters.
2. **Coherence check:** Run Gensim's `CoherenceModel` (C_v metric) for a range of topic counts (e.g., 2 to 15) and plot the coherence scores. Present the plot to the user and ask them to select the number of topics N before running the final model.
3. **LDA model:** Train `gensim.models.LdaModel` with the user-selected N topics on the preprocessed corpus.
4. **Visualization:** Use `pyLDAvis.gensim_models.prepare()` to generate an interactive HTML bubble chart saved to `lda_topics.html`.
5. **Top terms table:** Extract the top 10 terms per topic and present them in a Markdown table.

**For Group 9b (Hierarchical Descending Classification, IRAMUTEQ-style):** Run the following pipeline:

1. **Preprocessing with spaCy:** Same pipeline as 9a.
2. **TF-IDF matrix:** Use `sklearn.feature_extraction.text.TfidfVectorizer` to build a term-document matrix from the preprocessed abstracts.
3. **Ward hierarchical clustering:** Apply `scipy.cluster.hierarchy.linkage` with Ward method and `scipy.cluster.hierarchy.fcluster` to cut the dendrogram into K classes. Ask the user to select K (suggested range: 3 to 7).
4. **Dendrogram:** Render the dendrogram using `scipy.cluster.hierarchy.dendrogram` and `matplotlib`, with class labels and the top 5 chi-square-associated terms per class annotated on the plot. Save as `chd_dendrogram.png`.
5. **Class profile table:** For each class, compute the chi-square association between each term and the class (using `sklearn` contingency tables) and present the top 10 terms per class in a Markdown table, along with the percentage of text segments covered by each class.

*Important limitation to disclose:* This implementation approximates the Reinert method used in IRAMUTEQ. It uses Ward agglomerative clustering on a TF-IDF matrix rather than Reinert's original divisive chi-square algorithm. Results are comparable in structure but not identical. The R package `rainette` provides a more faithful implementation if the user requires strict methodological equivalence.

### Step 4 — Interpretive Commentary & Deliverable

Do not hand the user a folder of files without context. For every analysis generated, write a brief, data-grounded interpretation.

**Language Rules for Interpretation:**
- **No Hallucination:** Only describe what the data actually shows.
- **No Vague Adjectives:** Do not use words like "crucial," "dynamic," "fascinating," or "revolutionary."
- **Focus on Structure:** e.g., "The CHD dendrogram shows four lexical classes. Class 1 covers 34% of segments and groups terms related to 'evaluation,' 'indicator,' and 'policy.' Class 2 covers 28% and groups terms related to 'university,' 'mission,' and 'engagement.'"
