# Bibliometric and Scientometric Analysis

## The Problem This Solves

A literature review is not just about what papers say; it is also about how the field is structured. Who are the central authors? Which institutions collaborate? How have keywords evolved over time? Which papers form the intellectual backbone of the field?

This skill answers those questions by processing the OpenAlex JSON corpus generated by `verified-paper-search` through **pyBibX** (Pereira, Basilio & Santos, 2025), a state-of-the-art Python library for scientometric analysis. It generates interactive HTML visualizations and provides interpretive, data-grounded commentary.

## Workflow

### Pre-Flight: Verify Input Corpus

Before starting, you must locate the JSON file exported by `verified-paper-search` (e.g., `/home/ubuntu/articles/openalex_corpus.json`).

**If the file does not exist:** You must ask the user to provide it or to run `verified-paper-search` first.
**If the file exists:** Read the file to determine the size of the corpus (number of papers).

### Step 1 — Select Analyses (User Driven)

Do not run all analyses blindly. Present the following menu to the user, grouped by purpose. Note any corpus size warnings (e.g., networks require >20 papers; topic modelling requires >50).

| Group | Analyses Available | Purpose |
|---|---|---|
| **1. Descriptive/EDA** | Publications per year, citations per year, document types, languages | Basic overview of the field's size and growth |
| **2. Author Analysis** | Most productive authors, H-index table, author productivity plot | Identifying key researchers and their impact |
| **3. Source/Venue Analysis** | Most productive journals, Bradford's Law (core sources) | Identifying where the conversation is happening |
| **4. Geographic Analysis** | Countries per documents, world map collaboration | Mapping the global distribution of research |
| **5. Keyword Analysis** | Keyword co-occurrence network, term growth plot, WordCloud | Tracing how concepts and terminology evolve |
| **6. Citation Analysis** | Top cited references, Reference Publication Year Spectroscopy (RPYS) | Identifying foundational works and historical shifts |
| **7. Network Analysis** | Co-authorship network, institutional collaboration | Mapping the social structure of the field |
| **8. Advanced/Strategic** | Burst detection, Disruption index, Sleeping Beauties | Finding emerging trends and paradigm shifts |
| **9. Topic Modelling** | BERTopic clustering *(Requires >50 papers)* | AI-driven clustering of abstracts into themes |

**🛑 STOP: Ask the user which groups (or specific analyses) they want to run. Wait for their selection before proceeding.**

### Step 2 — Environment Setup & Data Bridge

Once the user selects the analyses, prepare the environment:

1. Install pyBibX: `sudo pip3 install pybibx`
2. If Group 9 (Topic Modelling) is selected, install BERTopic: `sudo pip3 install bertopic`
3. Write a Python script to load the OpenAlex JSON file into pyBibX. 

*Note: pyBibX accepts OpenAlex JSON natively via its `openalex_api` parameter, but if the JSON structure from the search step needs adaptation, use a Python script to format it into the CSV structure pyBibX expects before running the analyses.*

### Step 3 — Execution & Plot Generation

Execute the selected analyses using Python. Save the resulting plots (which pyBibX generates as interactive `.html` files) into a dedicated output directory (e.g., `/home/ubuntu/articles/bibliometrics/`).

*Fallback:* If pyBibX fails to install or crashes due to environmental constraints, fall back to generating static charts using `pandas` and `plotly` based on the JSON metadata.

### Step 4 — Interpretive Commentary & Deliverable

Do not just hand the user a folder of HTML files. For every analysis generated, write a brief, data-grounded interpretation.

**Language Rules for Interpretation:**
- **No Hallucination:** Only describe what the data actually shows.
- **No Vague Adjectives:** Do not use words like "crucial," "dynamic," "fascinating," or "revolutionary."
- **Focus on Structure:** e.g., "The keyword co-occurrence network shows two distinct clusters: one centered on 'evaluation' and another on 'policy'." or "The RPYS plot shows a significant peak in 2012, suggesting a foundational shift in the literature around that year."

**Deliverable Structure (`bibliometrics_report.md`):**

```markdown
# Bibliometric Analysis Report

**Corpus Size:** [N] papers
**Source:** OpenAlex

## [Analysis Group Name]

### [Specific Analysis, e.g., Keyword Co-occurrence]
- **Visualization:** Saved to `[Path to HTML file]`
- **Interpretation:** [Brief, data-grounded commentary on what the plot reveals about the field's structure]

*(Repeat for all selected analyses)*
```
